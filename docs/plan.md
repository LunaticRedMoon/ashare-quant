# A股多因子评分卡选股回测 — 项目计划

> 仓库：`ashare-quant` | 创建日期：2026-09-09 | 当前阶段：阶段 0（骨架搭建）

## 1. 目标

构建基于 **多因子 + 逻辑回归评分卡** 的选股模型，预测 **中证500 成分股 T+1 日收盘涨幅 > 3%** 的概率，输出「分数 → 胜率」的可解释映射，并回测验证其选股能力。

## 2. 协作模式

- **策略分析师（用户）**：定义策略逻辑、标签口径、评估指标，解读回测结果，拍板方向。
- **Coder / 执行（Hermes）**：数据获取、特征工程、评分卡建模、回测执行、出报告。
- **载体**：本 GitHub 仓库。策略分析师可 `git clone` 到本地练手（vibe coding），或在 QQ 上接收结果。

## 3. 定稿决策

| 维度 | 决策 |
|---|---|
| 技术路线 | 多因子 + ML 分类器 + 评分卡（WOE/IV + 逻辑回归 + 分数映射） |
| 标的 | 中证500 成分股（ETF / 全 A 后置） |
| 数据源 | akshare 日线（前复权）；券商 API 后置 |
| 标签 | 赢 = T+1 收盘涨幅 > 3%；输 = 反面 |
| 持有期 | 固定 T+1 单日，收盘结算 |
| 因子 | 动量因子起步 |

## 4. 技术路线

评分卡（Scorecard）流程：

1. 特征分箱（binning）
2. WOE 编码（每个 bin 的 ln(正样本占比 / 负样本占比)）
3. IV 筛选（Information Value，衡量因子预测力）
4. 逻辑回归（在 WOE 特征上拟合 P(赢)）
5. 分数映射（logit → 分数区间，分数与胜率严格单调、可校准）

**优势**：可解释、抗过拟合、概率校准，契合「优化胜率」的目标，同时避免胜率陷阱（高胜率但单笔收益极小）。

## 5. 阶段划分

- **阶段 0｜仓库与计划落地** ✅（当前）
- **阶段 1｜数据层**：akshare 取中证500 成分股日线（前复权）、成分股名单、剔除 ST / 停牌 / 次新
- **阶段 2｜标签工程**：构造样本 `(T日因子 → T+1 日涨跌幅)`，定义赢/输标签
- **阶段 3｜因子工程**：动量因子清单、分箱、WOE/IV、因子筛选
- **阶段 4｜评分卡建模**：逻辑回归、分数映射、单调性 / 校准验证
- **阶段 5｜回测与评估**：T+1 持有结算、评估指标、滚动训练、防过拟合
- **阶段 6｜券商 API 接入**：后置

## 6. 评估指标

- 胜率（命中率）
- 盈亏比（平均盈利 / 平均亏损）
- 扣费后收益
- 分数档位单调性、概率校准误差、高分段 vs 低分段胜率区分度
- 基准：中证500 指数同期表现

## 7. 风险与开放问题

- **胜率陷阱**：胜率必须配盈亏比和扣费收益一起看
- **未来函数**：因子时点必须与标签时点对齐（T 日收盘 → T+1 收盘）
- **过拟合**：滚动训练 + 样本外验证 + 单调性约束
